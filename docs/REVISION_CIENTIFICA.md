## Precisiones

- El contenido imposible no es un requisito universal para una idea delirante.
- Convicción y resistencia a la evidencia deben interpretarse culturalmente y en conjunto.
- Las obsesiones pueden tener insight variable.
- Una percepción delirante no equivale a alucinación: puede existir un estímulo real al que se atribuye significado delirante.
- Delirio y delirium se explican por separado.
- No se mantiene la atribución histórica a sexualidad reprimida como explicación causal establecida.
- La parafrenia y las clasificaciones clásicas se ubican en historia conceptual.
- El listado original de subtipos y la mezcla DSM/CIE no se presentan como clasificación vigente.
- No se asocia de forma automática religión, género, orientación sexual o diferencias culturales con enfermedad.
- El modelo de mezcla no reproduce una alucinación ni demuestra una alteración bayesiana general.

## Casos clínicos

Ocho historias totalmente ficticias con formulaciones provisionales. Incluyen primer episodio psicótico, delirium, Charles Bonnet, síndrome maníaco, depresión con síntomas psicóticos, síntomas temporalmente asociados a sustancias, obsesiones y experiencia hipnagógica. Se explicita qué falta evaluar. Las evoluciones son ilustrativas, no observaciones clínicas ni evidencia de eficacia.

Las decisiones de evaluación y abordaje se apoyan en las fuentes enlazadas en cada caso. No se incluyen dosis ni pautas farmacológicas. El uso docente debe reconocer que protocolos y recursos locales pueden diferir de las guías británicas.
